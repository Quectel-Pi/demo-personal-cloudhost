About this host

Quectel Pi M2 / RK3576 / Debian 13 is the target platform. Caddy serves this static site at /site/. This is a platform introduction, not live device telemetry.

The portal handles status, files and terminal access. This site demonstrates personal pages, documentation and static apps, without a new backend or an internet connection.

Publish your own page

  1. Open Files from the portal or connect over SSH. Find your configured site_dir; the default is ~/cloud/www (under cloud/www when Files opens your home directory).
  2. Back up index.html outside the public site directory. Edit its heading, or replace it with your own HTML; keep CSS, JS and images in the site directory using relative links.
  3. Save the file and refresh /site/ to show the change. No service restart is required. If necessary, bypass the browser cache.

Deployment installs the current demo homepage by default. A different existing index.html is backed up under /var/backups/cloudhost-site before replacement; other site files are kept. Use --keep-site when reinstalling to retain your custom homepage. Public sites must not contain secrets.
